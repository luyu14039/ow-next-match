# 数学模型与比较规范

生产实现为 TypeScript 纯数学函数；公开测试资料全部为合成序列，独立 Python 实现提供参考预测。参数是教学配置，不依据个人游玩记录优化。

## 0. 公平匹配假设与 math-v2 校正

暴雪在 [匹配目标说明](https://overwatch.blizzard.com/en-us/news/24224365/) 中将双方各有 50% 获胜机会称为理想情况；[匹配 FAQ](https://overwatch.blizzard.com/en-gb/news/23910161/overwatch-2-developer-blog-explaining-matchmaker-goals-and-plans-part-2/) 明确否认胜者／败者队列和强制玩家累计胜率。公平对局目标不能推导出“连胜以后必输”。本项目采用以下明确的实验假设，不还原官方匹配机制。

若假设每局相对于全部已有信息都完全公平，那么 `P(Y_(t+1)=1 | H_t)=0.5`，仅凭过去胜负就不能合理给出其他概率。长期平均胜率为 50% 是更弱的条件：例如胜负严格交替时，长期平均仍为 50%，但历史有预测信息。纳什均衡也不一般性地推出 50% 胜率。

math-v2 在下面的基础历史估计上应用共同收缩：

```text
p_raw = 基础模型从历史得到的估计
p = λ × 0.5 + (1 − λ) × p_raw
λ ∈ [0,1]，默认 0.5
```

λ=0 保留原始历史估计；λ=1 表达完全公平，所有模型严格为 50%；默认把历史偏差减半。比如原始 60% 校正为 55%。λ 是用户设置的假设强度，不是系统检测到的回归速度、状态变化频率、匹配算法概率或可靠性水平；默认 0.5 是教学选择，没有经验校准。

该表达可理解为“相信公平基准”与“相信历史估计”的概率混合。它是预测校正，**不是**对 MMR、对手分布或一个完整隐状态动态过程的生成式拟合。Beta、Markov、BOCPD 的历史状态仍按各自原算法更新；特别是 BOCPD 段长后验仍使用原 Bernoulli 似然，不能宣传为这个混合假设下重新推导的后验。

五个基础专家先校正，Hedge / Fixed-Share 再聚合这些概率，用同一份校正后概率计算 Brier 损失并更新权重。组合结果不二次收缩，避免重复改变偏差。首页、回放、Worker、评分和新赛前快照共享此实现。

若下一结果真实条件概率是 50%，任意预测 p 的预期 Brier 为 `0.25 + (p−0.5)²`。校正后的额外误差变为 `(1−λ)²(p_raw−0.5)²`，默认减为四分之一。这是理想公平条件下的数学性质，不是实际准确率提高的保证；真实概率偏离 50% 时，收缩可能损失有效信号。

下文基础公式描述 **原始历史估计**。默认最终值需应用以上校正。例如 10 局全胜的 Beta 原始值 75%，最终值 62.5%；Markov 原始值 14/19，最终值约 61.84%。

首次加载旧数据时，在 IndexedDB 乐观并发检查下新建 math-v2 配置，保留旧 math-v1 配置、记录、图片和所有赛前概率；旧配置缺失 λ 时按 λ=0 重现。配置升级不反写旧快照。恢复旧备份也执行相同升级；失败时不提交部分升级。

曲线只显示最近 20 条概率。纵轴根据当前展示模型自动选择范围，包含 50% 基准、有边距且跨度至少 10 个百分点；刻度范围和缩放状态始终显示，可切换至 0–100%。缩放不修改预测或评分。

## 1. 统一问题

对一个明确的上下文，令第 t 个有效结果为 y_t ∈ {0,1}，胜为 1，败为 0。模型在看见 y_t 之前输出 p_t，再用 y_t 更新状态。所有概率不依赖当前局尚未发生的时长、比分或赛后指标。

分位置上下文是 `dataset + scopeType(role-pooled-all-modes) + role`，**同位置的所有模式／队列共同入模**。unknown 位置不自动和任一已知位置合并；模式 unknown 但位置明确的记录仍参与。下文的窗口和场次都指当前选中范围流里的有效记录，不是首页显示的五局。

新增 `dataset + scopeType(all-roles-all-modes)` 的独立全部流，合并所有位置、包含未指定位置；其模型状态不平均或复用三位置状态。全部中的角色变化不打断相邻转移。

首页不给下一模式做条件化。不同模式可能存在不同分布，这是用户选择的合并估计；模式仅保留为分析维度，不能静默换回分模式模型。

第一版主要检验胜负序列，不加入地图、时长或段位回归系数。它们仍完整记录，未来要加入时必须明确定义“预测时是否已知”和独立的配置版本。

## 2. 模型清单

| 类别／ID | 参数 | 使用的信息 | 首页默认 |
| --- | --- | --- | --- |
| 固定基准 `fair50` | 无 | 无 | 否，分析基准常驻 |
| Beta `beta10`、`beta30` | Beta(5,5)，最近 10／30 条 | 近期胜负比例 | 可替换 |
| Markov `markov30` | 最近 30 个有效标签，每个转移行先验 5／5 | 上一有效结果及转移计数 | 是 |
| 变点模型 `bocpd` | Beta(5,5)，h=1/30 | 所有历史，潜在分段长度 | 是 |
| 专家混合 `hedge` | η=2，均匀初始权重 | 五个基础专家的过去误差 | 可替换 |
| 动态专家混合 `fixedShare` | η=2，γ=0.04 | 同上，允许权重重新分配 | 是 |

这是六类方法；Beta 两个窗口是同一类的两个实例。页面应显示清楚，不能宣传成七种独立理论。

基础专家池固定为 `[fair50, beta10, beta30, markov30, bocpd]`。Hedge 与 Fixed-Share 都只聚合这个池，互不聚合、不包含自己。首页三槽位的选择也不改变专家池。

## 3. 固定 50%：值得保留的零假设

`p_t = 0.5`。

假设下一局相对于已知历史完全公平。它没有训练和参数，是所有方法的同一参照。二分类时每一条的 Brier 都是 0.25，平均 Log Loss 为 ln(2) ≈ 0.6931。

若真实条件胜率为 0.5，给出更偏离 0.5 的概率通常只会增加预期平方误差。项目的成功条件是比较诚实、能解释结果，不是必须打败这个模型。

## 4. Beta–Bernoulli：收缩的近期胜率

对最近 W 条记录统计胜数 s 和败数 f：

```text
prior:       θ ~ Beta(α₀, β₀), α₀ = β₀ = 5
posterior:   θ | history ~ Beta(5 + s, 5 + f)
next p:      (5 + s) / (10 + s + f)
```

W=30 是主要版本，W=10 是短记忆专家。先验相当于 5 胜、5 败的平滑，使一两局不会直接报 0% 或 100%。10 局全胜时估计为 15/20=75%，不是百分之百。

每次重新统计窗口；滑出窗口的标签不再计数。这个后验是“所选窗口内胜率近似不变”的模型表达，不能解释成下一局真实胜率有经验证的 95% 保证。

科普说明：**最近记录影响估计，但小样本会向 50% 收缩。**

## 5. 一阶 Markov：条件概率与连胜直觉

取当前范围流中的最近 30 个有效标签。模式变化不自动打断；分位置栏先排除其他位置，全部栏则保留跨位置转移。只计入相邻且没有人为历史缺口／无效事件的转移，因此连续完整输入最多有 29 对。

令 N_ab 为从结果 a 转到 b 的次数。当前上一条结果为 a 时：

```text
p(next win | last=a) = (5 + N_a1) / (10 + N_a0 + N_a1)
```

没有上一条结果、刚好处于断点之后，返回 0.5；有上一条但对应行尚无转移样本，也返回 0.5。10 个连续胜利只有 9 对 W→W，预测为 14/19 ≈ 73.68%。

模型允许在数据里出现延续或反转，并不预先规定“连胜后必输”。它只看上一条的类型，不声称估计了疲劳、心理状态或队友水平。

科普说明：**总胜率相同的序列，条件概率可能不同。**

## 6. BOCPD 风格的 Bernoulli 分段模型

采用贝叶斯在线变点检测的思路，维护“当前状态段已经有多长”的分布。经典依据是 [Adams 与 MacKay，2007](https://arxiv.org/abs/0710.3742)；项目选择下面明确的“新状态在下一条结果之前开始”的索引约定，不声称逐字复现原论文全部实现。

### 状态

观察了 t 条标签后，q_t(k) 是当前段包含最近 k 条标签的后验概率。t>0 时 k=1…t。开始时 q_0(0)=1。

```text
μ_t(k) = (5 + 最近 k 条中的胜数) / (10 + k)
μ_t(0) = 0.5
h = 1/30
```

h 是每条有效记录前开始新状态段的先验概率，粗略对应平均 30 条的先验段长。这是可审阅的建模选择，不是守望系统的实际换队周期。

### 预测

```text
p_(t+1) = h × 0.5 + (1-h) × Σ_k q_t(k) μ_t(k)
```

不能忘掉 h×0.5 的新段分支，或把读完下一局结果后的状态用于预测那一局。

### 更新

看见 y 后，定义 `L(μ,y)=μ`（y=1）或 `1-μ`（y=0）：

```text
unnormalized_q_new(1)   += h × L(0.5,y)
unnormalized_q_new(k+1) += (1-h) × q_t(k) × L(μ_t(k),y)
q_new = unnormalized_q_new / sum(unnormalized_q_new)
```

新段计入刚观察的 y，旧段延长一条。第一次更新时 k=0 的延长项与重启项都落在 k=1，合并后 q_1(1)=1。每次更新检查概率非负、归一化和有限值。

第一版先用精确递推，不默默截断段长。用前缀胜数计算分段均值，每条更新 O(t)、完整回放 O(T²)，模型状态 O(T)。长记录回放放 Worker、分块并可取消；超过 5,000 条提示计算量并允许选择明确的历史窗口。若后续使用段长截断，应增加新模型版本并说明近似规则。

科普说明：**模型会在“状态延续”和“状态已经改变”之间分配概率。**

它检测的是记录中分布可能改变，不等于发现“匹配系统制裁”、玩家疲劳或明确的因果原因。

## 7. Hedge：以过去误差分配权重

五个基础专家在第 t 条结果之前给出 p_(i,t)，权重为 w_(i,t)：

```text
p_mix,t = Σ_i w_(i,t) p_(i,t)
loss_(i,t) = (p_(i,t) - y_t)²
u_i = w_(i,t) × exp(-η × loss_(i,t))
w_(i,t+1) = u_i / Σ_j u_j
```

初始权重均为 1/5，η=2。权重依据当前上下文的历史损失更新，不依据用户后来选择哪个图表、也不以当前局结果预先选模型。

长记录的生产实现用对数权重与稳定归一化避免小权重数值下溢；本轮短样例预检使用直接归一化，两者公式一致。

理论联系是 Prediction with Expert Advice：与候选专家比较自己的累计损失。这是现代在线学习和博弈学习的共同语言。默认固定 η 是简明教学配置；不由此宣称任意长度、任意数据下都有次线性的最坏情况遗憾，更不保证超过专家池里的最好方法。

科普说明：**过去表现更好的解释，会获得更多权重。**

## 8. Fixed-Share：给失宠专家重新参与的机会

先执行一次上述 Hedge 更新，得到归一化权重 v：

```text
w_(i,t+1) = (1-γ) × v_i + γ/K
γ = 0.04, K = 5
```

少量权重均匀回流，避免某个专家曾经失败后几乎永远无法重新参与。它适合展示“不同时间段可能由不同模型更合适”的想法。

这里采用允许回流到自身的均匀混合版本；原始文献也使用只向其他专家分配的参数约定。实现以本页公式为准，不直接照搬另一参数约定下的理论常数。

基础算法来自经典的 [Tracking the Best Expert](https://mwarmuth.bitbucket.io/pubs/J39.pdf)，并非 2026 年新发明。2025 年有动态专家跟踪的隐私扩展研究，但项目未实现差分隐私，也不能继承其保证，见 [研究依据](RESEARCH.md)。

科普说明：**环境变化时，之前不合适的模型也可能重新变得有用。**

## 9. 执行顺序和版本

```text
对每个上下文按确认顺序：
  1. 基础专家从过去状态 predict()
  2. Hedge / Fixed-Share 用过去权重聚合这些预测
  3. 保存全部模型概率、配置版本、使用的历史边界
  4. 读取这一条的真实标签，给全部概率记分
  5. 更新聚合权重，再更新基础专家状态
```

首页切换只决定展示哪些模型，不干预步骤 1–5。参数修改生成新的 configuration ID 和回放结果；旧的实际赛前快照保持原值。第一版不自动调参或采用看完整历史后才选出的“最佳参数”作为那段历史的事前预测。

## 10. 怎样判定预测得好

### 主要指标：Brier

`Brier = mean((p_t - y_t)²)`，越低越好。固定 50% 的二分类基准恒为 0.25。

`Brier Skill vs 50% = 1 - Brier / 0.25`，正值表示当前评分集合内优于基准，负值表示更差。UI 名称是“相对 50% 基准改善”，不用“准确率提升”。

### 次要指标：Log Loss

`-mean(y_t ln(p_t) + (1-y_t) ln(1-p_t))`，越低越好。只为避免 log(0)，在算此指标时把概率夹到 `[1e-12, 1-1e-12]`；不把模型输出人为限制到 40%–60%。

### 方向与校准

可以展示“偏胜／偏败”的方向命中；严格 p=0.5 记 0.5 个方向分，标签为“方向得分”，不冒充标准分类准确率。概率在 48%–52% 的 UI 文案显示“接近五五开”，这只是阅读提示，不改变评分。

校准图按概率分箱比较平均预测和实际胜率。样本不足 100 条时默认折叠，展开仍显示每箱场次；100 是界面可读性阈值，不是统计可靠性的保证。三个模型的概率范围叫“模型分歧范围”，不能叫真实胜率置信区间。

### 公平比较

排名移入分析栏目，使用所有启用模型均有预测的同一个样本集合，显示 n、位置、合并范围、记录来源、评分起止、配置版本。按模式查看误差只过滤快照，不重新生成分模式概率。冷启动的第一局也计入，不能某个模型删掉差成绩后重新排名。累计 Brier 曲线、最近 20 条评分是不同视图，标题必须清楚。

“历史回放”和“实际事前快照”不混合排行榜。合成样例的结果只能称作“样例回放领先”，不能写“最准确模型”。参数被人为依据这份历史调过后，即使执行顺序正确，这份回放也不再是独立样本外评价。

## 11. 为什么没有直接套 Elo 或纳什均衡算胜率

Elo／Bradley–Terry 的对局概率依赖两边的相对实力。这里只有一个玩家的胜负，缺少对手或两队实力；同时估计玩家进步和对手变化，存在可辨识性问题。第一版不制造一个隐藏分再用它证明自己的概率。

纳什、CCE 和 OFTRL 描述有策略、收益与反馈的参与者如何学习；胜负日志没有提供这些变量。它们适合可选的猜硬币／收益矩阵演示，而不是给未知队友的下一局虚构一个均衡胜率。近期方法的去留理由见 [研究依据](RESEARCH.md)。
