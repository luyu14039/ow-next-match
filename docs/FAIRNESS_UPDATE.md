# 公平假设、模型说明与阅读体验更新

日期：2026-10-07。

## 变更

- 新增共同的 50% 回归强度，默认 50%，0% 至 100% 可调。完全公平时全部模型输出 50%；组合模型按校正后误差学习，避免重复收缩。
- 旧记录自动升级到新配置，保留旧配置与已锁定概率；备份兼容旧、新版本。
- 七个模型弹窗补充通俗概念、分步计算、当前参数对应的数字示例、建模假设和局限；公式与组合权重折叠展示。
- 标题使用衬线字体，正文和控件用系统无衬线，概率用展示数字字体，公式与刻度用等宽字体。保留此前调大的阅读字号，字体使用系统回退，无外部字体请求。
- 分析和历史改为“预测走势”“对局记录”等具体名称，删除口号式文案。
- 曲线动态纵轴包含 50% 参照和全部可见点，显示当前范围，可切回完整刻度。

## 数学边界

共同校正表达对公平匹配的信任程度，不是逆推出守望先锋的 MMR 或匹配周期。默认强度未经现实样本校准。只有在真实条件概率为 50% 时，向 50% 收缩有明确的预期平方误差收益；对有规律的历史不保证提高预测效果。详见 [数学说明](MODELS.md)。

## 验证

- Vitest：42 项测试通过，包括 strict fairness、校正后专家损失更新、旧预测复现、旧备份恢复、原子迁移与双窗口迁移竞争，以及动态纵轴边界。
- 独立 Python 标准库实现重新生成 60 条合成序列的逐局预测／评分，以及全部、坦克、输出、辅助四个范围和八个追加分支；TypeScript 逐项一致。
- Playwright 在 1440×1000 桌面与 390×844 手机视口实测，使用单独浏览器中的 100 局合成数据。七个弹窗均可打开、阅读、展开公式和关闭；组合权重可显示，手机无横向溢出。
- 实际操作回归滑块：100% 后三个首页值均为 50.0%；0% 后恢复原始估计，刷新仍保留设置与 100 局记录；最终恢复默认 50%。
- 动态轴显示 40–60% 时可切换至 0–100%，再恢复自动缩放；图表方向键显示对应逐局概率。
- 生产构建与同源 OCR 资源检查通过，合成测试 fixture 未打包入站点。本轮未改动 OCR 识别算法，未重新执行整套截图识别验收。

线上部署由仓库的 GitHub Actions 工作流执行，运行结果见 GitHub Actions；本地界面截图留在忽略目录 output/playwright，不包含个人历史。
